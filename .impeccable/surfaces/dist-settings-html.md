# Settings surface

## Mode

Operate: help the extension owner find and change a preference quickly.

## Design read

Personal browser-extension settings for a Coursera learner, using the same quiet, light, Coursera-blue language as the popup.

## Direction

- Keep the page calm and compact, with a clear product header and the selected open-book C logo.
- Use a responsive white surface on a cool light-gray page, thin dividers, and blue only for active and focused controls.
- Separate course-backup options from general preferences with accessible tabs.
- Preserve existing control IDs and storage behavior while improving labels, focus, and status feedback.
- After settings save successfully, tell the user to refresh the Coursera tab if the changes have not appeared.

## Constraints

- No unrelated navigation, account/usage panel, pricing prompt, or expiry-date display.
- Keep settings and action feedback truthful; do not imply a task completed without a completion signal.
